# Responsive E-Commerce Frontend (`e-shop`)

A clean, modern, and fully responsive e-commerce landing page and front-end interface built with vanilla web technologies. Designed to provide a seamless shopping experience across desktop, tablet, and mobile devices.

---

## 🚀 Features

- **Fully Responsive Design:** Adapts fluidly to various screen sizes using modern CSS Grid, Flexbox, and media queries.
- **Interactive Navigation:** Dynamic header shadow effect on scroll and a functional mobile toggle menu.
- **Product Showcases:** Dedicated sections for featured items, active shop inventory with pricing, and new arrivals.
- **Newsletter Subscription:** Clean form layout for user engagement.
- **Clean Code Architecture:** Structured using standard HTML5 semantic elements and modular CSS/JS files.

---

## 🛠️ Built With

- **HTML5:** Semantic markup and structure.
- **CSS3:** Custom styling, Flexbox, CSS Grid, variables, and responsive media queries.
- **JavaScript (ES6+):** DOM manipulation, event listeners, and interactive navigation logic.
- **Boxicons:** Scalable vector icons for social media, user accounts, and shopping cart elements.

---

## 📂 Project Structure

```text
├── index.html       # Main HTML structure and semantic layout
├── style.css        # Global styles, variables, components, and media queries
├── main.js          # Interactive UI logic (scroll effects and mobile menu toggle)
└── img/             # Product images, logos, and visual assets
```
